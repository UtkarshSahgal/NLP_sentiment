# Movie Review Sentiment Analysis

## Overview
This project performs sentiment analysis on IMDb movie reviews using NLP techniques.

## Features
- Text preprocessing
- TF-IDF feature extraction
- 3 ML models + hyperparameter tuning
- Visualization (word cloud, graphs, confusion matrix)

## Models Used
- Naive Bayes
- Logistic Regression
- SVM
- Tuned models using GridSearchCV

## Results
Achieved ~90%+ accuracy with SVM.

## How to Run
1. Create virtual environment
2. Install requirements.txt
3. Run notebook
